# NEXORA — Immersive Website

A cinematic single-page experience built from scratch with vanilla HTML, CSS and JavaScript.

## Highlights

- Layered parallax and pointer-reactive depth
- Canvas particle field with lightweight spring/attraction physics
- Magnetic buttons and floating interactive chips
- Scroll progress and section navigation
- IntersectionObserver reveal animations
- Animated impact counters and data visualizations
- Responsive mobile layout
- Reduced-motion accessibility support
- No framework or build step required

## Run

Open `index.html` directly in a browser, or serve the directory with any static HTTP server.

## Structure

- `index.html` — semantic page structure
- `styles.css` — visual system, responsive layout and animations
- `script.js` — parallax, particles, interactions and counters
